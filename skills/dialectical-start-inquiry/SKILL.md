# Start Inquiry

Begin or branch an inquiry in this conversation.

Infer a short working focus and carry forward only relevant visible material,
including useful disagreement and uncertainty. Ask one question if the topic is
missing; otherwise begin discussing it. A new inquiry may be related to earlier
thinking. Do not require an intake form, invent an ID, or claim to create a new
platform chat or a stored record.

Only when the user requests a persistent workspace or is already using an
authorized Dialectical file store, read
[the file procedure](references/file-storage.md) and its shared storage contract
before accessing or initializing it. Preserve existing records and provenance;
keep inquiry selection, canonical writes, and index updates in the conversational
agent. Ordinary startup requires no storage or service.
