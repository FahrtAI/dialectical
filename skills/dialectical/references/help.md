# Canonical help card

When the user asks for Dialectical-specific help, return the following card as
written. Preserve the banner's spacing and keep each operation description to
five words.

```text
 ____  ___    _    _     _____ ____ _____ ___ ____    _    _
|  _ \|_ _|  / \  | |   | ____/ ___|_   _|_ _/ ___|  / \  | |
| | | || |  / _ \ | |   |  _|| |     | |  | | |     / _ \ | |
| |_| || | / ___ \| |___| |__| |___  | |  | | |___ / ___ \| |___
|____/|___/_/   \_\_____|_____\____| |_| |___\____/_/   \_\_____|

Ordinary conversation with intellectual discipline.

GUIDE               Recommend one useful conversational operation.

RESTATE             Rephrase an idea without judgment.
SUMMARIZE           Compress the conversation without interpretation.
DISTILL             Extract insights, tensions, and questions.
TRACE               Recover where an idea originated.

RELEVANCE           Clarify inquiry purpose and scope.
COLLECTION GAPS     Identify missing evidence worth seeking.
INDICATORS          Define observable signals worth watching.

RESEARCH            Find relevant evidence and precedents.
HYPOTHESIZE         Generate plausible competing explanations deliberately.
THOUGHT EXPERIMENT  Explore implications through imagined conditions.

CHALLENGE           Seek weaknesses and disconfirming evidence.
VERIFY              Check claims against available evidence.
ACH                 Compare competing hypotheses against evidence.
CAUSAL-CHAIN        Test each link in causation.
SOURCE-QUALITY      Rate source reliability and credibility.

TAG                 Attach useful labels for retrieval.
SAVE                Prepare knowledge for later reuse.
RECALL              Retrieve previously saved relevant knowledge.

START INQUIRY       Begin exploring a focused question.
CHECKPOINT          Capture current state for continuation.
RESUME              Continue a previously saved inquiry.
CLOSE               Close while preserving the inquiry.
```

Do not use this card for a generic request such as “help me with this problem.”
It is for requests to explain Dialectical, show its operations, or explain how
to use the toolkit.

For examples by situation, ask to see the cookbook or sample flows. The flow
guide can be shown without starting any operation. You can also type `/MAN` or
`/?` for a compact menu of the operation card, cookbook, and sample flows.

For `/MAN`, `/?`, or `/HELP`, use this compact menu before showing a selected
reference:

```text
Dialectical orientation:

[1] Operation card
[2] Cookbook and pathways
[3] Sample flow
```

Wait for the user's choice. A menu choice only retrieves orientation material;
it does not authorize an operation.
