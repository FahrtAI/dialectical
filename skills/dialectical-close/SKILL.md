# Close Inquiry

Leave the inquiry recoverable without closing the platform chat.

Use the shortest complete response that preserves material evidence,
provenance, disagreement, and unresolved uncertainty. For a clear
ordinary-language invocation that does not name CLOSE, begin with one line:
`CLOSE — <brief context-specific description>.` Omit the cue for an explicit
command or mere discussion. Change a claim's scope or confidence only when the
stated evidence or analysis justifies it.

Return a final distillation with the current assessment, evidence and its limits,
uncertainty, reversals, and open questions. Mark the inquiry paused or closed as
requested within the conversation; explain that the copyable note can be pasted
into another chat. Unresolved work stays unresolved. Do not claim a durable save.

For a user-authorized file store, read
[the file procedure](references/file-storage.md) and its shared storage contract
before taking the final distillation and changing status. Keep mutations in the
conversational agent. Never automatically delete, merge, or save other objects.
