# Dialectical backlog

Future work, design questions, and ideas are tracked in the
[Dialectical GitHub Project](https://github.com/orgs/FahrtAI/projects/1).
Repository issues are the source of truth; this file deliberately does not
duplicate their descriptions or status.

## How work is organized

- **Status:** Todo, In progress, or Done.
- **Work type:** Feature, Research, Documentation, Infrastructure, Bug, or Decision.
- **Priority:** Now, Next, or Later.
- **Area:** Conversation, Skills, QA, Packaging, or Governance.

An idea belongs in an issue once it has enough context to discuss. Moving an
issue forward should add concrete scope and acceptance criteria. Inclusion in
the Project is not authorization to implement or publish it.
